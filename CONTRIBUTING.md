# Contribuir

Propón cambios con fuente primaria, fecha y aptitud. Mantén IDs, progresos y contratos; crea migraciones para cambios de estado. No incluyas secretos, datos personales ni dumps de examen. Antes de un PR ejecuta `pnpm check`, `pnpm build:pages` y las E2E pertinentes. Describe qué cambió, por qué y qué pruebas corriste; no declares revisión no realizada. Para contenido generado por herramientas, revisa respuestas y distractores antes de marcar aptitudes verificadas.
